# CS340
- The program I wrote is adaptable and maintainable, because the underlying scaffold of the project is solid. There are three main components to the dashboard which include the MongoDB server, the python CRUD module, and the Dash dashboard. In my CRUD module, I added functionality to change the default credentials, so that the module if flexible to different credentials.
 
- As a computer scientist, I linked the raw data given to me by Grazioso Salvare to a MongoDB instance using Docker. This allows me to easily query specific data that Grazioso Salvare wanted to prioritize for their search rescues. I created a CRUD module that interfaces with the database, and the web dash board, and I hade graph components that dynamically showed pertinent data for a selected animal, which also serves to give more context to specific geolocation data. The most important technique to creating applications that rely on a database for other client requests is modularity, having clear deliniations of functionality, helps you understand how each component builds on top of each other to make a desireable user experience.

- Computer scientists deal with understanding and using computer technologies, this can present itself as furthering research into novel computational techniques, or delivering products to integrate services with computer technology.
